Chapter 24

명령어 카드·용어집·종합 퀴즈

마지막 장은 책을 덮은 뒤에도 곁에 두고 찾아보는 참고 자료실이다. 검색과 필터가 되는 명령어 레퍼런스 카드, 32비트 명령어의 주 opcode 지도, 레지스터·CSR 카드, ISA 매뉴얼 v20260120에 실린 확장 전체를 한 장에 모은 확장 지도, 장별 링크가 달린 용어집이 들어 있다. 끝에는 1장부터 23장까지를 한 문제씩 되짚는 24문항 종합 퀴즈가 기다린다.

  • 명령어 이름·확장·형식으로 명령을 찾고, 비트 필드와 실제 인코딩 예를 확인한다.
  • opcode 지도에서 32비트 명령어 공간이 어떻게 나뉘어 있는지 한눈에 본다.
  • 정수·부동소수점 레지스터의 ABI 이름과 자주 쓰는 CSR 주소를 찾는다.
  • 비준된 확장이 규격 문서와 이 책의 어느 장에 있는지 지도로 찾아간다.
  • 용어집으로 핵심 용어를 복습하고, 종합 퀴즈로 책 전체를 점검한다.

명령어 레퍼런스 카드

아래 카드는 RV32I·RV64I 베이스, M, A, F·D(주요 명령), Zicsr·Zifencei, C(주요 명령), Zba·Zbb·Zbs, Zicond, 그리고 특권 명령(mret, sret, wfi, sfence.vma, hfence.* 등)을 담고 있다. 인코딩 값은 ISA 매뉴얼 v20260120의 명령어 목록(비특권 35장, 특권 18장)과 B·Zicond 장의 인코딩 그림에서 옮겼다. 먼저 32비트 명령의 여섯 가지 기본 형식을 다시 떠올려 보자(4장).

주 opcode 지도

32비트 명령의 하위 두 비트 inst[1:0]는 언제나 11이다(00·01·10은 16비트 압축 명령의 세 사분면). 남은 inst[6:2] 다섯 비트가 32가지 주 opcode(major opcode)를 고른다. 규격의 표는 inst[6:5]를 행으로, inst[4:2]를 열로 놓는다.

압축 명령(13장)도 같은 방식의 지도를 가진다. 하위 두 비트 op가 사분면을, 상위 세 비트 funct3(inst[15:13])가 칸을 고른다.

레지스터 카드

정수 레지스터의 ABI 이름(3장, 7장)과 부동소수점 레지스터의 ABI 이름(12장)을 한 장에 모았다. 이름과 역할은 RISC-V psABI의 호출 규약 표를 따른다.

CSR 빠른 표

CSR 주소는 12비트이고, 상위 비트에 접근 규칙이 들어 있다(17장). 규격은 “상위 두 비트 csr[11:10]는 읽기/쓰기(00·01·10)인지 읽기 전용(11)인지, 다음 두 비트 csr[9:8]는 접근할 수 있는 가장 낮은 특권 수준을 나타내며 10은 하이퍼바이저 CSR”이라고 정한다.

확장 지도

ISA 매뉴얼 v20260120의 목차에 실린 확장을 무리별로 모았다. 위쪽은 1권(비특권), 아래쪽은 2권(특권)이다. 이름을 누르면 그 확장을 다루는 이 책의 장으로 간다. Svade·Ziccif 같은 프로파일 정의 이름, AIA·SBI처럼 ISA 매뉴얼 밖에 있는 규격은 지도에 넣지 않았다(23장, 22장).

용어집

이 책에 나온 핵심 용어를 한국어 정의와 함께 모았다. 각 항목의 링크는 그 용어를 자세히 다룬 장으로 간다. 먼저 오늘의 용어 카드로 가볍게 몸을 풀자.

핵심 정리

  1. 32비트 명령은 inst[1:0]=11이고 inst[6:2]의 주 opcode로 크게 갈린다. 그 안에서 funct3·funct7(또는 funct5·funct6·고정 즉시값)가 명령을 고른다.
  2. rs1·rs2·rd는 모든 형식에서 같은 자리에 있고, 즉시값만 형식마다 흩어진다. R4 형식은 융합 곱셈-덧셈에 쓰인다.
  3. 16비트 압축 명령은 op 두 비트(00·01·10)로 사분면을, funct3로 칸을 고르며, 같은 칸이 RV32·RV64에서 다른 명령일 수 있다.
  4. 정수 레지스터는 zero·ra·sp·gp·tp·t·s·a, 부동소수점 레지스터는 ft·fs·fa로 나뉜다. s와 fs는 피호출자 저장이다.
  5. CSR 주소의 [11:10]은 읽기 전용 여부, [9:8]은 최저 특권을 나타낸다.
  6. 확장 지도와 용어집의 링크를 따라가면 어떤 개념이든 이 책의 해당 장과 규격 원문으로 바로 돌아갈 수 있다.

종합 퀴즈

1장부터 24장까지 한 장에 한 문제씩, 모두 24문제다.

[1장] 다음 중 ISA가 정하는 것은?

트랩이 났을 때 mepc·mcause 등이 어떻게 바뀌는지는 ISA(특권 규격)가 정한다. 나머지는 마이크로아키텍처의 자유다.

[2장] ISA 이름의 G가 뜻하는 조합은?

규격의 이름 규칙 장은 G를 “IMAFDZicsr_Zifencei” 묶음의 약자로 정의한다. C는 따로 붙인다(RV64GC).

[3장] addi x0, x5, 7을 실행하면?

x0에 쓰기는 무시된다. rd=x0인 이런 명령 중 일부는 HINT 인코딩으로 쓰이기도 한다.

[4장] B 형식의 오프셋이 늘 짝수(2의 배수)인 이유는?

B·J 형식은 imm[0]을 생략한다. 4바이트 단위로 하지 않은 것은 압축 명령(IALIGN=16)과 맞추기 위해서다.

[5장] 의사 명령 li a0, 0x12345678은 보통 어떤 명령들로 바뀌나?

상위 20비트는 lui, 하위 12비트는 addi로 채운다. addi가 부호 확장하므로 하위가 음수면 상위에 1을 더해 보정한다.

[6장] RV64I에서 addw의 결과는?

W 명령은 32비트 결과를 만들고 항상 부호 확장해 rd에 쓴다. 그래서 RV64에서 32비트 int 연산이 자연스럽다.

[7장] 표준 호출 규약에서 정수 함수의 첫 번째 인자와 반환값이 들어가는 레지스터는?

a0–a7(x10–x17)이 인자 레지스터이고, a0·a1이 반환값을 담는다.

[8장] 5단 파이프라인에서 lw 바로 다음 명령이 그 결과를 쓰면(load-use)?

RISC-V에는 적재 지연 슬롯이 없으므로 하드웨어가 해저드를 감지해 거품을 넣는다.

[9장] div a0, a1, a2에서 a2=0이면?

RISC-V는 0으로 나누기에 트랩을 두지 않는다. 필요하면 소프트웨어가 분기 하나로 검사한다. 나머지(rem)는 피제수가 된다.

[10장] sc.w가 성공했을 때 rd에 쓰이는 값은?

성공하면 0, 실패하면 0이 아닌 값을 쓴다. 그래서 bnez로 재시도 루프를 만든다.

[11장] RVWMO에서 서로 다른 주소로의 “저장 후 적재” 순서를 다른 하트에게도 지키게 하려면?

RVWMO의 보존 프로그램 순서(PPO)에는 서로 다른 주소의 저장→적재 순서가 들어 있지 않다. fence.i는 명령어 페치용이다.

[12장] FLEN=64인 하트에서 flw로 단정밀도 값을 적재하면 f 레지스터의 상위 32비트는?

좁은 값은 상위 비트를 모두 1로 채워 저장한다. 그래야 잘못 박싱된 값을 넓은 연산이 NaN으로 본다.

[13장] C 확장(또는 Zca)이 있으면 IALIGN은?

압축 명령이 섞이면 명령 주소가 2바이트 경계에 놓일 수 있으므로 IALIGN이 16으로 줄어든다.

[14장] Zba의 sh2add rd, rs1, rs2가 계산하는 것은?

rs1을 2비트 왼쪽으로 민 뒤 rs2에 더한다. int 배열의 주소 계산(base + index×4)에 딱 맞는다.

[15장] VLEN=128, SEW=32, LMUL=2일 때 VLMAX는?

VLMAX = LMUL × VLEN / SEW = 2 × 128 / 32 = 8.

[16장] Zicond의 czero.eqz rd, rs1, rs2에서 rs2가 0이면?

“rs2가 0이면(eqz) 결과를 0으로” 만들고, 아니면 rs1을 그대로 쓴다. 두 개를 조합하면 분기 없는 선택이 된다.

[17장] CSR 주소 0xC01(time)의 상위 두 비트 11이 뜻하는 것은?

csr[11:10]=11은 읽기 전용이다. csr[9:8]=00이므로 U 모드도 읽을 수 있다(카운터 허용 비트가 켜져 있다면).

[18장] mcause의 최상위 비트가 1이면?

Interrupt 비트가 1이면 인터럽트, 0이면 예외이고, 나머지 비트가 원인 코드다.

[19장] Sv39 페이지 테이블은 몇 단계이고 기본 페이지 크기는?

39비트 가상 주소 = 9+9+9비트의 VPN 세 단계 + 12비트 오프셋. 중간 단계의 잎 PTE는 2 MiB·1 GiB 슈퍼페이지가 된다.

[20장] PMP 항목 i가 TOR 모드일 때 영역의 아래 경계는?

TOR은 pmpaddr(i−1) ≤ 주소 < pmpaddr(i)를 잡는다(항목 0이면 아래 경계 0). 2의 거듭제곱 크기는 NAPOT 방식이다.

[21장] H 확장의 G-stage 변환이 하는 일은?

VS-stage(vsatp)가 게스트 가상 → 게스트 물리를, G-stage(hgatp)가 게스트 물리 → 실제 물리를 맡는 2단계 변환이다.

[22장] S 모드 커널이 SBI를 호출할 때 확장 ID(EID)를 넣는 레지스터는?

SBI 호출 규약은 a7에 EID, a6에 함수 ID(FID)를 넣고 ecall한다. 오류 코드는 a0, 값은 a1로 돌아온다.

[23장] RVA22U64에서는 옵션이었고 RVA23U64에서 필수가 된 것은?

V는 RVA23U64에서 필수가 되었다. RVA23S64에서는 하이퍼바이저(H, Sha)도 필수다.

[24장] 주 opcode 지도에서 custom-0~custom-3의 의미는?

규격은 custom-0~3을 표준 확장이 피할 공간으로, reserved는 미래 표준 확장이 쓸 수 있으니 사용자 정의가 피해야 할 공간으로 구분한다.
